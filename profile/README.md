<h3 align="center">Tessh</h3>

<p align="center">
  A calm, native SSH client for Mac and iPhone.<br>
  <a href="https://tessh.dev">tessh.dev</a>
</p>

---

- **Native on both.** SwiftUI on macOS and iOS, no web views.
- **Device keys.** Made in your device's security chip and never leave it. Unlock with Touch ID or Face ID.
- **Synced keys and hosts.** End-to-end encrypted. The server only ever sees ciphertext.
- **Everything you reach for.** Jump hosts, proxies, port forwarding, SFTP, agent forwarding, certificates.
- **Host it yourself.** The sync server runs as one Docker container with an owner panel.
